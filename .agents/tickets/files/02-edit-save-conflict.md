# 02 — 编辑保存（防抖 + 脏标记 + 冲突检测）

**What to build:** 编辑器可编辑：修改文本 → 停止输入约 800ms 自动保存到磁盘（文件名旁出现脏标记 ·，保存后消失）；打开文件时记录 mtime + 内容哈希快照，保存时服务端校验磁盘现状——已被外部修改（mtime 或哈希不符）则返回冲突，前端弹三选（覆盖 / 放弃 / 重新加载）。服务端新增 `pi:writeFile`（expected 快照校验 + 只读/二进制/过大拒绝写 + 路径防护复用）；写操作同样限定 cwd 内。

**Blocked by:** 01 — 文件浏览（目录树 + 只读打开）

**Status:** ready-for-agent

- [ ] 编辑后约 800ms 自动保存，脏标记出现与消失正确；保存成功有轻量反馈
- [ ] 外部修改文件后保存 → 冲突弹窗三选：覆盖（强制写）/ 放弃（丢弃编辑恢复磁盘内容）/ 重新加载（载入新内容继续编辑）
- [ ] 只读模式（过大/二进制/目录）不出现保存路径；路径越权写被服务端拒绝
- [ ] 服务端冲突检测逻辑有单测（hash 不符 / mtime 不符 / 一致放行 / 越权拒绝）；前端脏状态机为纯函数有单测
- [ ] `npm test` + `npm run typecheck` 全绿；浏览器冒烟：编辑真实文件落盘 + 外部修改触发冲突三选
