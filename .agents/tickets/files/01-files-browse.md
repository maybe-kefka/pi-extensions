# 01 — 文件浏览（目录树 + 只读打开）

**What to build:** `/files` 页面上线：左侧目录树（以 pi 进程 cwd 为根，按需展开单目录，默认排除 node_modules/.git/dist/.pi 与隐藏文件——两个开关可切换显示，手动刷新按钮）+ 右侧编辑器区（CodeMirror 6 容器，只读打开文本文件；>500KB 显示"过大只读"；二进制嗅探拒绝打开并提示）。服务端新增文件安全域（路径规范化 + `..` 逃逸拒绝 + symlink 逃逸防护 + 目录列举 + 二进制/大小分类）与 `pi:listDir`/`pi:readFile` RPC；所有路径操作仅限 cwd 内。侧栏导航新增入口。

**Blocked by:** None — can start immediately.
