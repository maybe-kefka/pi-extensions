# 01 — 布局树领域层：跨组拆分 + join 落点 + 单 tab 守卫

**What to build:** 布局树（split 二叉树）纯函数层的拖拽语义升级：落点判定从"四向边缘 / 无"扩展为"四向边缘 / 中央 join"；拆分动作支持把任意组的 tab 拆到目标组（跨组拆分：从源组移除、目标组一分为二、tab 放入新组、空组自动回收）；join = 追加目标组末尾并激活；单 tab 守卫（源组 = 目标组 且源组仅 1 个 tab 时拆分返回原树）。同组拆分的既有行为不变。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 落点判定：左/右/上/下边缘（25% 贴边）返回对应方向；中央返回 join
- [ ] 跨组拆分：tab 在 A 组，drop 到 B 组左缘 → B 一分为二、tab 入新组（左侧）、A 移除该 tab 且激活相邻；A 空则回收
- [ ] 同组拆分行为与现状一致（现有测试全部保持绿色，除明确标注的语义更新）
- [ ] 单 tab 守卫：源组 = 目标组且 tabs=1 → 拆分返回原树
- [ ] join：目标组追加末尾 + 激活；源组空自动回收
- [ ] 全量测试绿：npm test（该层单测新增 + 既有）+ typecheck
